# Задачи

## Посты

1) Создание поста (Сделать логику что бы создавали только писатели и админы)
2) Получение всех постов
3) Получение определённого поста по пользователю
4) Получение опредлённого поста по id
5) Получение всех моих постов
6) Обновление поста по id
7) Сокрытие поста по id
8) Удаление поста по id (Не забыть очистить комментарии к данному посту)

## Комментарии

1) Создание комментария (Сделать логику что бы создавали только >= пользователя, плюс было подвязан к посту)
2) Получение всех комментариев к посту
3) Изменение комментария (Может только тот кто его создал)
4) Удаление комментария (От редактора до админа)
