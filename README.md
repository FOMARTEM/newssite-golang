# REST API новостоного сайта

Мой первый pet-проект, который изначально создавалася в качестве итогового задания по курсу "Языки интернет программирования".
В начальной версии была только главаная страница с поставми и создание/авторизация пользователя. Вскоре были
добавлены комментарии, лайки, уровни пользователей. Так же были добавлены функции и процедуры в БД, для
упрощения работы с ней.

## Технологии

1. Golang
2. HTTP
3. Echo
4. JWT
5. Postgresql

## Инструкция по запуску

1. Выполнить все sql файлы из директории ``` /internal/provider/database ``` (создание БД, таблиц, функций и процедур)
2. В директории ``` /config ``` создать файл ``` config.yaml ```, которой необходимо заполнить по примеру из ``` example.yaml ```
3. В корневой директории проекта запустить скрипт ``` run.sh ```

    ``` bash
        ./run.sh
    ```

## Как работать с данным API

В директории лежит файл ``` example.sh ```, в котором находятся примеры ``` curl ``` запросов к API.
Необходимо заменить данные в запросах и URL к которому идёт запрос.
В качестве первого пользователя советую создавать супер админа которому вручную будет
присвоен максимальный уровень доступа.
